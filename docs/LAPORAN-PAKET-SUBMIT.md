## 5 · Langkah yang tersisa di dasbor Vercel

### 5.1 · Mengaktifkan AI (butir 3)

1. Google AI Studio → **Get API key** → **Create API key** → salin.
2. Vercel → proyek **zippyverse** → **Settings → Environment Variables**.
3. Tambah variabel `GEMINI_API_KEY` → tempel nilai → **Save**.
4. **Deployments → … → Redeploy** — *ini langkah yang paling sering terlupa*;
   variabel lingkungan hanya terbaca saat proses dibangun ulang.
5. Uji: `POST /api/zippy` dengan `{"message":"hai zippy","history":[]}`.
   - `mode: "fallback"` → masih gagal.
   - `mode: "gemini"` → **berhasil**.

### 5.2 · Menyambungkan Git agar push memicu deploy (butir 5)

1. Vercel → **Add New… → Project → Import** → pilih
   `FooTex16/ZIPPYVERSE-EDUCATION-WEBSITE`.
2. Pastikan *Framework Preset* = **Next.js** dan *Root Directory* = `.`
3. Salin keempat variabel di §4 dan §5.1 ke **Environment Variables**.
4. **Deploy.** Sejak itu setiap `git push` ke `main` memicu deploy otomatis.

## 6 · Catatan tentang konversi PDF/DOCX

| Hal | Keterangan |
| --- | --- |
| Alat | **pandoc 3.12.1** (`C:\Users\ThinkPad\AppData\Local\Pandoc\pandoc.exe`) |
| Mesin PDF | **`typst` 0.15.1** — dipasang lewat winget karena pandoc **tidak menemukan `pdflatex`, `xelatik`, `wkhtmltopdf`, maupun `weasyprint`**. Uji coba pertama PDF **gagal** tepat karena itu; setelah `typst` dipasang, seluruh PDF berhasil |
| Mesin DOCX | pandoc bawaan — langsung jalan sejak uji pertama |
| Pemformat | `-f gfm` (GitHub-flavored Markdown) agar seluruh **tabel pipe** terbaca; daftar isi tingkat 2 untuk dokumen ringkas, tingkat 1 untuk log mentah |
| Pemeriksaan kualitas | PDF: header `%PDF-` + `%%EOF` valid, halaman dihitung. DOCX: `word/document.xml` dibuka, jumlah `<w:tbl>` dan gaya judul dihitung |
| **Keterbatasan yang perlu Anda tahu** | **Model ini tidak mendukung membuka PDF**, sehingga saya **tidak bisa melihat hasil cetaknya sendiri**. Yang bisa saya pastikan hanya struktur: berkas valid, jumlah halaman wajar, dan tabel terbawa ke DOCX. **Mohon buka satu atau dua PDF untuk memastikan tampilannya rapi di layar Anda.** |
